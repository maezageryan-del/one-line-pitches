[![Reward](https://make.fun/badge/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3/maezageryan-del/one-line-pitches/reward.svg)](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)

A program that writes one sentence to convince a friend who has never coded
to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## The line

> That app idea you keep talking about only needs one sentence: describe it in plain words on make.fun and an AI agent builds your first version tonight — free, no code, yours only if you love it.

The pitch in one breath: the idea the friend already carries only needs one
sentence of plain words; an AI agent builds a working first version tonight;
it costs nothing to try, needs no code, and the friend keeps it only if they
love it.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The line is
194 characters, inside the 1–240 character gate.
